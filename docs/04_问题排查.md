# 问题排查

> 遇到问题先查这里；没有的记下来，解决后补进来（同步给AI遵守）。

## 后端

| 症状 | 原因 | 解决 |
|------|------|------|
| `uvicorn` 命令找不到 | 没激活虚拟环境 / 没装依赖 | `.\venv` 换成 `.venv\Scripts\activate`；`pip install -r requirements.txt` |
| `ModuleNotFoundError: xxx` | 依赖没装 | 检查 requirements.txt 是否包含，`pip install xxx` |
| `/api/health` 502 | 端口被占用 | 换端口：`--port 8001` |
| API Key 报 401 | .env 没配 / Key 错误 | 检查 `.env` 的 `DEEPSEEK_API_KEY`，重启后端 |
| chromadb 导入报错 | 版本冲突 | `pip install -U chromadb`，或换 Python 3.11 环境 |
| chromadb 跨进程 "Error loading hnsw index" | 本机 Windows 环境 bug（1.5.9/0.5.23 均复现） | 已改为自实现 numpy+SQLite 向量检索，不依赖 chromadb |
| 导入/评估脚本与后端同时跑导致数据错乱 | 向量库并发访问 | **导入/评估前先停后端**（uvicorn） |
| CORS 跨域 | 前端端口和后端不一致 | 后端允许 `http://127.0.0.1:5173`（阶段0配置） |

## 前端

| 症状 | 原因 | 解决 |
|------|------|------|
| `npm install` 慢/失败 | 网络 | 换淘宝镜像：`npm config set registry https://registry.npmmirror.com` |
| `npm run dev` 端口占用 | — | 改 `vite.config.ts` 的 port |
| 页面调后端报跨域 | 后端没配 CORS | 见后端 CORS 行 |
| 前端构建报 TS 类型错 | 类型没同步 | 后端改接口后同步更新 `frontend/src/api/types.ts` |
| 测试时中文问题总被"拒答" | 用 PowerShell `Invoke-RestMethod` 发中文请求，GBK 编码会乱码 | 用 Python/httpx 或前端发请求（UTF-8）；PowerShell 请写 `-Body` 前转 UTF-8 字节 |

## 部署（阶段4）

| 症状 | 原因 | 解决 |
|------|------|------|
| 国内服务器访问慢 | 用了 Vercel | 换轻量云服务器 |
| Docker 拉镜像失败 | 网络 | 配国内镜像源 |
| 手机打不开 | 端口/防火墙 | 检查安全组放行端口 |
| 部署后 Key 泄露风险 | .env 进了镜像/仓库 | 用服务器环境变量，`.env` 不进 git 不进镜像 |
