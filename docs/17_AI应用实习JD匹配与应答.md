## 二、针对这个岗位的 30 秒项目介绍

> "我做了一个企业 AI 智能办公助手，本质就是 **三条可迭代的 AI Agent 工作流**：
> ①知识库问答（RAG：检索→带来源推理→确定性拒答→评估集保证质量）；
> ②信息提取（数据进入→清洗→AI 三路提取客户/项目/公司→**人工确认**→结构化入库，自生长闭环）；
> ③客户实体问答（"张三什么情况"→AI 汇总）。
> 架构上我把大模型封装成统一适配层、提示词集中成可复用模板、质量用评估集量化。我负责定架构和规则，AI 按规则实现、我验收——这正是 Agent 工作流工程化的日常协作方式。"

## 三、面试可能被问的 5 题（针对此岗）

**Q1：你理解 Agent 工作流吗？你的项目哪里体现了？**
> 理解。Agent 工作流 = 把"目标"拆成"数据获取→处理→推理→输出"的可执行步骤，并让人能介入校验。我的信息提取模块就是：源文件获取（上传/扫描/ASR）→ R1 清洗 → R2 提取 → 人工确认 → 入库，每步独立、可替换。

**Q2：RAG 和 Agent 有什么区别？**
> RAG 是"检索增强生成"——给模型外挂知识库，重点是"答得对、有来源"；Agent 是"任务编排"——让模型按流程拆步骤、调工具、做多轮。我的知识库是 RAG，信息提取是更接近 Agent 的编排，两者互补。

**Q3：你的 Prompt 体系怎么设计的？**
> 原则：集中管理、规则化、可复用。每个模板固定输出格式（JSON/markdown 四段）、防编造（只依据输入）、诚实（无信息写"待确认"）。改提示词只改一处，不散落。

**Q4：怎么保证生成质量？**
> 三层：①检索质量用金标评估集量化（命中率 100%）；②答案可信靠确定性拒答（相似度阈值）+ 来源标注；③提取结果靠人工确认闭环。用数字和流程兜底，不靠运气。

**Q5：你最想在这个岗位学到/贡献什么？**
> 我对"把大模型工程化落地成可持续迭代的工作流"已经有一整套实践（适配层/提示词体系/人机协作闭环），希望在这里把它做成能处理真实业务数据的系统——比如内容自动生成、跨境数据结构化，正是我项目"信息提取"的延伸。
