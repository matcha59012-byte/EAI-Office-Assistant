# 前置环境配置

> 本机已验证：Python 3.11.15 ✓ / Node 24 ✓ / Git 2.54 ✓
> 开发期在本地跑，部署见阶段4。

## 1. 需要准备的账号

| 项 | 操作 | 费用 |
|----|------|------|
| DeepSeek API Key | 注册 platform.deepseek.com → 创建 API key → 充值 | 几元即可，演示用量极小 |

## 2. 后端环境

```bash
cd D:\寻找工作\EAI-Office-Assistant\backend

# 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
copy .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY="sk-xxxx"

# 启动
uvicorn app.main:app --reload --port 8000
# 浏览器打开 http://127.0.0.1:8000/docs 应看到 FastAPI 接口文档
```

## 3. 前端环境（阶段0创建后使用）

```bash
cd D:\寻找工作\EAI-Office-Assistant\frontend
npm install
npm run dev
# 浏览器打开 http://127.0.0.1:5173
```
