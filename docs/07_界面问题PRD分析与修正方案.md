## 3. 根因分析（按模块拆）

### 模块 A：数据层 → P3 md 空白（已实证定位）

**现象**：点开示例文档（如 财务报销流程.md）中栏空白。
**证据**（实测数据库）：
```
doc#1 [办公用品领用与采购流程.md]  kb_chunks=0
doc#2 [考勤管理制度.md]            kb_chunks=0
doc#3 [请假管理制度.md]            kb_chunks=0
doc#4 [财务报销流程.md]            kb_chunks=0
```
**根因链**：
1. 评估脚本 `scripts/eval_kb.py` 的 `seed_samples()`：把文档写入 `documents` 表 + 写入 **chroma 向量库**，但**没有写 `kb_chunks` 表**（切片只进了向量库，没进 SQLite）。
2. 接口 `GET /api/kb/documents/{id}/content` **只从 `kb_chunks` 表拼内容** → 对示例文档返回 `content=""`。
3. 中栏 DocViewer 拿到空串 → md 渲染空白。
4. 走"上传"接口的文档（会写 kb_chunks）正常 → 所以只有**预置示例文档**全空，看着像"md 组件坏了"，其实是**数据没落库**。

**修复方向（选更稳的）**：
- `documents` 表加 `content` 列：上传/导入时**存全文**。
- `content` 接口直接返回 `document.content`（不依赖切片表，最稳）；kb_chunks 仅用于检索。
- 修复 `seed_samples` 写入 content；**写一次性修复脚本**把现有 4 个示例文档补上全文。
- 这样 md 显示与"是否切片"彻底解耦，未来 pdf/docx 也不怕。

### 模块 B：界面布局 → P1 顶栏两行、P2/P2.1 按钮固定

**P1 顶栏两行**：当前是"logo+Tab"一行。改为：
- 第1行：`E-AI Office Assistant · 企业AI智能办公助手`（品牌行，浅色/玻璃底）
- 第2行：功能 Tab（知识库/会议纪要/客户数据）

**P2/P2.1 按钮移动**：分析两条可能：
- 可能1：你看到的是**上一版缓存**（绝对定位修复在最新代码里）——需 Ctrl+F5 复验；
- 可能2：绝对定位让按钮贴在"行右边缘"，面板变窄时右边缘左移，视觉上按钮在动。
**修复方向**：每个列表行 = `flex`，左侧图标+文字（`flex:1;min-width:0`），右侧固定宽操作区（`flex-shrink:0`），按钮不再受文字宽度影响；同时行内滚动改为面板级滚动，避免拖拽时重排抖动。

### 模块 C：联动 → P4 来源跳转

跳转本身逻辑没问题（`doc://{id}` 点击→打开中栏），只是被 P3 拖累。**P3 修好，跳转即恢复**。另补充：跳转后高亮目标文档（左栏选中态）。

### 模块 D：视觉 → P5 Apple 玻璃拟态

macOS 玻璃质感实现要点（纯 CSS，无新依赖）：
```
背景层：浅灰渐变  #f5f5f7 → #e8e8ed（macOS 系统外观）
玻璃面板：background: rgba(255,255,255,0.55);
          backdrop-filter: blur(24px) saturate(180%);
          圆角 12-14px；边框 1px solid rgba(255,255,255,0.5)；
          阴影 0 8px 32px rgba(0,0,0,0.06)
顶栏：半透明白玻璃 + 模糊，内容在上方滚动时透出
消息气泡：用户=半透明蓝、AI=白色玻璃
选中态：半透明蓝 #1677ff40
字体：PingFang SC（macOS 中文字体）
```
- 只改样式层（CSS/token），不动业务逻辑。
- 浅色为主，预留暗色变量。

## 7. 风险与注意

| 风险 | 应对 |
|------|------|
| 浏览器缓存导致"看起来没改" | 每步完成后提示 Ctrl+F5；关键 bug 以数据库/接口实测为准 |
| backdrop-filter 兼容性 | Edge/Chrome 支持良好；留 `@supports` 降级为半透明白 |
| 玻璃效果影响性能 | 面板数量少，可接受；如卡顿降低 blur 到 16px |
| content 字段迁移 | 一次性脚本：示例文档从 sample_data 回读填充，用户上传文档从切片表回填 |

---

## 8. 一句话结论

**md 空白不是渲染问题，是"示例文档只进了向量库、没进内容表"的数据 bug（已实测证据），上传的文档一直正常。** 修复数据层即可让 md 与来源跳转全部恢复；再改顶栏两行、按钮固定、Apple 玻璃换肤。分 7 步实施，每步测试 3 遍，满意后再提交。
