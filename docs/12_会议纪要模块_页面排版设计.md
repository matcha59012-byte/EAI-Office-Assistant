## 2. 各区域详细设计

### 2.1 左栏「源文件区」

| 元素 | 功能 | 说明 |
|------|------|------|
| **[上传音频]** | 上传 MP3/MP4 | 上传后自动进入 ASR 转写流程（MiMo），状态显示"转写中→转写完成" |
| **[上传 md/txt]** | 上传会议纪要 md/txt | **txt 自动转 md**（加标题/元信息头） |
| **[扫描待处理]** | 触发自动提取 | 扫描源文件夹的新文件 → 自动 R1-R3 → 进入"待确认" |
| 源文件列表 | 文件 + 状态标签 | 状态：待处理 / 转写中 / 待提取 / **待确认** / 已归档 / 已跳过 |
| 分组筛选 | 待处理 / 待确认 / 已归档 | 快速找到当前要处理的文件 |

> **上传音频 = 工作流第①步**；上传 md/txt = 第②步的替代入口（已有文字纪要时直接用）。

### 2.2 中栏「文档 + 提取预览区」

**Tab1 会议纪要查看**
- 渲染选中源文件内容（md）
- ASR 转写中时：显示进度条 + 状态（分段数/当前段）
- 转写产物 = 会议纪要 md（Speaker Map + 逐句转写 + 术语纠错记录）

**Tab2 实体提取预览**
- 对选中源文件点"提取"后显示 R2 三路结果：
  - **客户/人物卡片**：姓名/公司/角色/软信息/行事风格5维/项目看法
  - **项目卡片**：背景/利益相关人/决策/争议/预算/时间线
  - **公司卡片**：企业信息/组织架构/管线/运营模式
- 每条卡片带 **R3 diff 标记**：🔄更新（对比旧值）、🆕新增、✅无变化
- 每条底部标注"来源：\<源文件\>"

### 2.3 右栏「确认 + 实体库区」

**Tab1 待确认实体**
- 按 实习期CRM方案 提交顺序分组：客户 → 项目 → 公司
- 每条卡片：关键字段摘要 + 来源链接
- 操作：[确认✓] [跳过✗]，顶部 [全部确认]
- **确认后 → 卡片写入知识库实体层，左栏源文件状态 → 已归档**

**Tab2 已归档实体**
- 客户/项目/公司 三组列表
- 点击实体 → 完整卡片 + 来源追溯
- 后续（阶段3）：客户卡片自动进入"客户数据"模块

## 3. 文件状态流转（回答"保存到哪里"）

```
上传MP3 ─▶ 转写中(asr) ─▶ 会议纪要md入库(源文件) ─▶ 待提取
上传md/txt ─▶ 源文件(待提取) ──────────────────────┘
        │                                              │
        └──扫描/手动点提取──▶ 待确认(pending)
                                  │
                    ┌─────────────┴─────────────┐
                  [确认✓]                     [跳过✗]
                    │                           │
             实体卡片 → 实体层                  标记已跳过
             (客户/项目/公司, 来源可追溯)
             源文件 → 状态"已归档"               源文件 → 状态"已跳过"
             （同时归档到"会议纪要"资料库可检索）
```

**保存位置总结**：
| 内容 | 存到哪里 |
|------|---------|
| 会议纪要源文件（md） | `meeting_sources` 表 + "会议纪要"资料库（文档层，可检索问答） |
| 实体卡片（客户/项目/公司） | `entities` 表（实体层），带 `source_meeting_id` 溯源 |
| 待确认队列 | `pending_extracts` 表 |
| 音频原件 | 服务器上传目录（不入库） |

## 4. 操作流程演示（用户视角，5 步）

1. **左栏 [上传音频]** 选 MP3 → 中栏 Tab1 显示"转写中..." → 完成后生成会议纪要 md → 源文件列表新增（状态：待提取）
2. 选中该文件 → 中栏 Tab1 看纪要（Speaker 标注的逐句转写）
3. 点中栏 **Tab2「提取」** → 出现客户/项目/公司三路卡片（带 🆕/🔄 标记）
4. 右栏 **Tab1 待确认** → 逐条 [确认✓]/[跳过✗] → 确认的卡片归档
5. 左栏该文件状态变"已归档" → 右栏 **Tab2 已归档** 可查；后续自动扫描新文件重复 1-4

## 6. 验收标准（排版层面）

- [ ] 三个区域各司其职：左=源文件、中=文档/提取预览、右=确认/实体库
- [ ] 上传音频、上传md/txt、扫描 三入口都在左栏固定位置
- [ ] ASR 转写有明确进度反馈
- [ ] 提取预览卡片清晰、diff 标记明显、来源可追溯
- [ ] 确认操作一键完成（确认/跳过/全部确认）
- [ ] 确认后状态流转到"已归档"，实体可在"已归档"查看
- [ ] 玻璃风格与知识库一致，窗口缩放无空白
