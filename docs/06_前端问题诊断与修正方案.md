## 2. 根因分析（技术层面）

### P1 排版/空白/不适配 —— 根本原因：布局用了"死值"
- `KnowledgePage` 高度写死 `calc(100vh - 200px)`，和真实可用高度对不上 → 底部空白；窗口缩放就错位。
- 整个页面出现 **5 个窄列**：`App侧栏(200) + 文档列表(200) + 文档内容 + 会话列表(180) + 聊天内容`，每列都被挤窄。
- 各面板固定像素宽度、不可折叠、不可调宽 → 空间利用差。

### P2 查看窗口"报废" —— 根因：没有 md 渲染器
- `DocViewer` 把内容当纯文本渲染，markdown 的 `#/##/**` 全部裸露 → 视觉上像坏掉。功能其实正常（接口返回了全文），是**展示层缺失**。

### P3 引用不能删 —— 根因：Tag 是"纯展示"，没有关闭逻辑
- `ChatPanel` 里 `askDocId` 的标签只显示不可关；且"点文档即自动带上引用"这个交互太激进，没有给用户选择权。

### P4 折叠 —— 根因：没做面板化管理
- 全部是固定 div，没有"折叠/展开/拖拽"能力；antd 的 `Splitter`、`Collapse` 都没用上。

### P5 会话改名 —— 根因：后端没有改名接口，前端没有改名 UI
- 只有"首句自动命名"，无 `PUT` 接口，前端无可编辑输入。

### P6 md —— 与 P2 同根因：前端缺 markdown 渲染库。

### P7 排版知识 —— 承认：本次布局是"拼出来的"，没有按现代布局规范做。

## 3. 现代前端排版知识要点（你要求"越新越好"）

**视口与自适应**
- 用 `100dvh`（动态视口高度，含移动端地址栏收缩）替代 `100vh`；`100svh`/`100lvh` 视场景。
- 整页不滚动，改为"容器内部各自滚动"（每栏 `overflow: auto`），桌面工具类 UI 的标准做法。

**布局模型**
- 主布局一律 flex/grid，禁止用固定像素高度猜。
- App 外层：`height:100dvh; display:flex; flex-direction:column`，Header 固定，Content `flex:1; overflow:hidden`，内层再分行/分列。
- flex 子项加 `min-width:0`（否则内容会把列撑爆）、`flex:1 1 0`。
- 面板可折叠/可拖拽：antd `Splitter`（v5.21+ 官方可拖拽分隔面板）或 `react-resizable-panels`。

**折叠模式（参考 opencode / Obsidian）**
- 左侧栏：可折叠成图标条（宽 ~48px），点击展开（~240px），Obsidian/VS Code 风格。
- 文档列表/会话列表：顶部标题 + 折叠按钮，可整组收起。
- 引用来源：默认收起，点开才展开。

**视觉与主题**
- 颜色/间距用 CSS 变量（token）统一，暗色主题预留。
- 卡片化适度：只有消息/文档用卡片，容器用分隔线，减少"拼图感"。

- **渲染 md（文档 + 聊天回答）**：`react-markdown` + `remark-gfm`（最轻、最主流）。

- **布局**：用 antd `Splitter` 做可拖拽三栏 + 自绘折叠侧栏，无需额外重库。

## 5. 修正方案（逐问题）

### 修正A：布局重做（P1/P4/P7）
- 全屏 App 壳：`100dvh` + Header + Content(flex:1, overflow:hidden)。
- 知识页改成 **三栏可折叠、可拖拽**：
  - **左栏（折叠式）**：文档库 + 会话历史（Tab 或分组），默认 240px，可折叠成 48px 图标条。
  - **中栏（主区，占大头）**：文档查看器（md 渲染），`flex` 大权重。
  - **右栏（可收起）**：AI 问答（复用 ChatPanel），可一键收起成细条。
- 每栏独立滚动，整页不滚动；窗口缩放自适应（无空白、无溢出）。

### 修正B：md 渲染（P2/P6）
- 引入 `react-markdown` + `remark-gfm`。
- `DocViewer` 文档内容 → md 渲染（标题/列表/表格/加粗正常显示）。
- `ChatPanel` 的 AI 回答 → md 渲染（回答本身是 markdown）。

### 修正C：文档引用可控（P3）
- 打开文档 = 只"查看"，**不自动**带进提问。
- 提问框旁提供显式开关"基于当前文档提问"，打开后显示可移除 Tag（带 ×）。
- 点 × → 清除引用，文档仍可继续查看。

### 修正D：会话改名（P5）
- 后端加 `PUT /api/kb/sessions/{id}`（body: `{title}`）。
- 前端：会话标题双击可编辑；新会话默认名"新会话"，不再强制用首句命名（保留自动命名，但可随时改）。

### 修正E：折叠与空间利用（P4）
- 左栏折叠、右栏收起、来源折叠（antd Collapse / 自绘）。
- 空间不够时优先保证中栏文档区，聊天收起后仍有历史图标入口。
