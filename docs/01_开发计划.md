## 阶段1：模块A · 企业知识库问答（RAG）⬜

**目标**：传文档 → 提问 → 带引用来源的答案。

| # | 任务 | 验收标准 |
|---|------|---------|
| 1.1 | 文档上传：`POST /api/kb/upload`（md/txt 起步，pdf/docx 跟进） | 上传成功、列表可见、可删除 |
| 1.2 | 切片与向量化：段落切片 → chromadb 入库 | 上传后能检索到 |
| 1.3 | 问答：`POST /api/kb/ask` → 检索TopK → DeepSeek生成 → 返回 sources | 答案对 + 能点开来源 |
| 1.4 | **强制检索拒答规则**：检索相似度低于阈值 → 返回"未检索到相关文档"（确定性规则，不靠LLM自觉） | 问库外问题返回拒答提示 |
| 1.5 | **金标评估集**：10-20条"问题→期望来源"的评估集 + 自动测试脚本（跑完输出来源命中率） | 脚本能跑，命中率≥80% |
| 1.6 | 前端问答页：上传 + 提问 + 来源展示 | 网页全流程跑通 |

> 1.4/1.5 借鉴黑马"智慧问诊Agent"的"强制检索+诚实拒答+评估门禁"方法论（文章思路，非代码）。

**阶段1验收**：传一份公司制度 md，问"报销流程是什么"能答且带来源。
