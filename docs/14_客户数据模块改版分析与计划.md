## 二、根因分析

1. **方向错了**：我把客户数据做成了"管理表"（列表+表单+看板），但你要的是"**可问答的实体知识库**"。实体卡片已经是 实习期CRM方案 格式（信息提取产出），但**没有变成可检索的知识源**。
2. **UI 照抄了 antd 默认控件**，没按 macOS/iOS 玻璃风格设计（分段控件、胶囊、透明弹窗）。
3. **编辑用表单而非 md**，与"Obsidian 式"不符，且只有客户字段，没做 3 实体通用。
4. **看板定位不清**：混入无关内容，缺少"总量/时间进度/工作进度"的数据化呈现。
5. **跟进交互单一**：状态应可随时切换，不是只进不退。

## 三、改版方案（逐点对应）

### 1. 左侧列表：iOS 分段控件（Segmented Control）
- 客户/项目/公司 → **一段玻璃胶囊**（`flex:1` 三等分占满宽度，选中态半透明白）
- 状态筛选（新/跟进中/静默/已关闭）→ 同样式胶囊
- 去掉蓝色实心按钮，全部走 `.mac-btn` 玻璃胶囊风格（毛玻璃+圆角+半透明）

### 2. 编辑改版：Obsidian 式 md 编辑器 + 灰色透明弹窗
- **方案A（推荐）**：详情页内直接编辑 `card_md`（Markdown 编辑器），保存时**解析 md 回填结构化字段**（按 实习期CRM方案 模板章节解析）；退出前弹"是否保存？"
- **方案B**：保留表单但做成玻璃弹窗（背景灰色透明 + 毛玻璃）
- 我推荐 **A**（符合你 Obsidian 习惯 + 最优），实现一个通用 `MdCardEditor` 组件
- 弹窗：`Modal` 深色半透明背景、毛玻璃卡片、可关闭（Esc/×），关闭前询问保存
- **支持编辑 3 种实体**（客户/项目/公司），字段定义统一

### 3. 详情状态切换
- 详情页顶部状态区域：点当前状态 → 弹选择（跟进中/静默/已关闭/取消）
- 后端 follow 已支持传 status，前端改为**状态下拉/弹窗切换**，随时可切可回

### 4. 详情页 → 实体信息详情
- 客户/项目/公司共用同一个详情组件（实习期CRM方案 md 卡片 + 状态 + 关联跳转）
- 看板里的"项目/公司"按钮删除；实体信息在详情页通过关联（linked 字段）查看/跳转

### 5. 编辑 3 实体
- `MdCardEditor` 按实体类型加载对应模板字段 + 可编辑 md 正文

### 6. 看板重做
- **6.1 数据卡片**：客户X个 / 公司Y个 / 项目Z个 + 各自状态分布（纯数字卡，无冗余）
- **6.2 项目时间轴**（可实现，见下）：项目实体增加 `start_date/end_date_est` 结构化字段；时间轴组件按项目显示进度条（未开始/进行中[按日期插值%]/已完成/已延期），当前日期标线
- **6.3** 看板 = 总量 + 时间进度 + 工作进度（状态分布），干净的数据视图

### 7/8. AI 实体问答（本次最核心）
- **客户数据模块右侧新增「实体问答」Tab**（复用 ChatPanel + 实体检索）：
  - 把实体卡片 `card_md` **向量化入库**（复用 numpy+SQLite 向量检索，标记 entity 来源）
  - 问题 → 检索相关客户卡片 + **关联展开**（linked_projects/companies 一起取出）→ DeepSeek 总结
  - 例："张三什么情况" → AI 汇总：归属公司/参加项目/项目进度/需求/沟通风格，附来源卡片可点击跳转
- **知识库侧（可选增强）**：知识库问答可加"实体知识源"选项，让 /ask 也能搜到客户实体
- 这彻底实现"客户数据=可问答的实体知识库"

### 9. 前端排版（改版后总览）


## 四、关键技术可行性评估

| 技术点 | 可行性 | 方案 |
|--------|--------|------|
| 项目时间轴（按当前时间推算进度） | ✅ 可行 | 提取提示词增加 `start_date/end_date_est`；前端按 (今天-start)/(end-start) 算进度%，antd Progress + 自绘时间轴 |
| Obsidian 式 md 编辑器 | ✅ 可行 | 引入 markdown 编辑器（`@uiw/react-md-editor` MIT 或 bytemd MIT），或 textarea+预览；保存时按模板章节解析回填 |
| 实体问答 | ✅ 可行 | 复用 numpy 向量检索 + ChatPanel；实体卡片向量化入库 + 关联展开 |
| 玻璃分段控件 | ✅ 可行 | CSS 自绘（毛玻璃+胶囊），无新依赖 |
